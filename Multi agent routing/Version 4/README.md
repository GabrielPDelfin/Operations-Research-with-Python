Agents need to return to their starting node.

There are a limited number of trips an agent can perform. Each trip has a maximum of T movements an agent can perform.

Each agent can travel a fixed number of distance units per trip.
An agent is allowed not to travel in certain trips.
If trip 2 is used then trip 1 must also be used etc.

The new index is:
- R: Number of trips an agent can perform.

the new parameter is:
- Max_Distance = 10

The new variable is:
- Use_trip: Binary. Indicates whether an agent uses a trip or not
